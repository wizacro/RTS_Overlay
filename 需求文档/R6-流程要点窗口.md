## 1. 可行性调研结论

**能提取**。解剖了你导入的 5 个真实流程（AoE2）后确认：

- 流程步骤没有结构化的科技/兵种字段，但每条说明文字里都用 `@图标路径@` 标记内嵌了图标
- 图标路径前缀 = 建筑分类（`stable/` 马厩、`blacksmith/` 铁匠铺、`mill/` 磨坊……），同一文件夹内既有该建筑生产的**兵种**（如 `stable/Knight_aoe2DE.png` 骑士），也有该建筑研究的**科技**（如 `stable/BloodlinesDE.png` 血统），还有建筑本身（如 `Mill_aoe2de.png`）
- 资源/村民/野生动物/时代图标（`resource/`、`animal/`、`age/`）可以精确排除，不混入重点

**分类规则**（AoE2）：维护一张"图标 → 类别 + 中文名"映射表（JSON，随仓库发布、可持续补充）：
- 已知条目：骑士、侦察骑兵、弩手、手炮兵、僧侣、巨型投石机 = 兵种；血统、锻造、箭羽、马轭、双刃斧、织布、采金 = 科技（基于实际出现的图标整理，共约 30 条）
- 未收录的新图标：按文件夹归入兵种/科技候选，名称显示英文原名（不猜错）——映射表可随时补充中文
- 村民/资源/动物/时代图标一律排除；"主要"= 按流程中**首次出现的顺序**去重排列

## 2. 界面设计

点击"**开启悬浮窗**"时（悬浮窗展示前），弹出一个独立的**流程要点窗口**：

```
┌─ 流程要点：15 min Knight Spam ──────────┐
│ 文明：Khmer ｜ 步骤：14 步 ｜ 来源：buildorderguide │
│                                          │
│ ⚔ 主要兵种（按流程出现顺序）             │
│   [骑士图标]  [侦察骑兵图标]  [骑士图标]… │
│   骑士        侦察骑兵                    │
│                                          │
│ 🔬 主要科技（按流程出现顺序）             │
│   [血统]  [锻造]  [箭羽]  [马轭]          │
│   血统      锻造      箭羽    马轭        │
│                                          │
│ 💡 建议先浏览一遍流程说明，再进入游戏     │
│                          [开始游戏，关闭] │
└──────────────────────────────────────────┘
```

- 窗口为普通窗口（不置顶、不阻挡），关闭后不影响悬浮窗开启
- 在展示页**每次选中不同流程**时同步刷新内容（悬浮窗开着时更换流程也会更新）
- 展示页额外加一个"**流程要点**"按钮，随时可重新打开
