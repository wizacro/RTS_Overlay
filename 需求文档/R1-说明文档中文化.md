## 3. 改动方案

**方式**：就地翻译 `Readme.md`（整文件替换为中文版），不做双语并存。理由：本 fork 定位就是"中文修改版"，访问者打开仓库主页即见中文；双语并存会让每次上游同步要维护两份，违背"最省事"原则。

**保留不动的元素**：
- 所有 Markdown 结构（标题层级、表格、列表、代码块、HTML 标签）
- 全部图片路径（`/readme/*.webp`、`/docs/assets/**`）与外部链接 URL
- 代码块、命令行示例中的代码与文件名（不翻译）
- 行尾格式 CRLF；编码输出为 UTF-8（中文化后必然不再是纯 ASCII，GitHub 按.UTF-8 渲染，无问题）

**顶部说明**：文档开头加一行中文说明"本文档为中文译版，英文原文见[原项目](https://github.com/CraftySalamander/RTS_Overlay) vX.XX"，满足 GPL 署名与溯源要求。

**锚点处理**：文首目录（Table of contents）的站内锚点链接须同步改为中文标题在 GitHub 上生成的锚点（中文标题的锚点会保留中文，如 `#主说明与下载`），确保目录点击可跳转。

**术语表**（全文统一）：

| 英文 | 中文 |
|------|------|
| build order | 建造顺序 |
| overlay | 悬浮窗 |
| panel | 面板 |
| hotkey | 快捷键 |
| web version / EXE solution / Python solution | 网页版 / EXE 版 / Python 版 |
| civilization (civ) | 文明 |
| major god | 主神 |
| AoE2 / AoE4 / AoM / SC2 / WC3 | 帝国时代2 / 帝国时代4 / 神话时代 / 星际争霸2 / 魔兽争霸3 |

游戏内术语首次出现时保留英文括注（如"建造顺序（build order）"），避免玩家对不上游戏原文。
