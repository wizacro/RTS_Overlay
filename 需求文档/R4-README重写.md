## 1. 背景

R1 翻译的 README 描述的是**旧版单窗口界面**（"配置面板"、"建造顺序选择"、面板截图等章节），与 R3 改版后的实际界面已不符。需基于新功能与新交互重写。

**重要事实**：EXE 下载链接指向原项目发布页（2.15.0），那是**旧版界面**编译的；新版管理器界面目前只能从本 fork 源码运行。README 必须如实区分。

## 2. 新 README 结构大纲

1. **简介**：中文版声明（基于上游 2.15.0）+ 双窗口定位（管理器负责管理、悬浮窗负责展示）+ 隐私特性（不与游戏交互）
2. **目录**（锚点重建）
3. **快速上手**：四步流程（① 导入建造顺序 → ② 选择与配置 → ③ 开启悬浮窗（移动模式）→ ④ 固定模式进游戏），每步 2-3 句话，与新用户第一眼体验对齐
4. **管理器详解**：
   - 导入页：游戏下拉（切换游戏）、流程数量与流程网站、剪贴板导入 + 名称栏规则
   - 展示页：搜索与筛选（空搜索显示全部）、右键重命名/删除（移入弃用区说明）、悬浮窗开关与移动/固定模式
   - 折叠区：外观（背景色/不透明度/字号/缩放/**显示行数** 1-5）、展示控制、快捷键
   - 底栏：保存设置 / 界面主题 / 退出
5. **悬浮窗详解**：移动模式（整窗拖动、可预览试按）、固定模式（按钮可点+其余穿透）、四个按钮（开始/停止计时*、上一步、下一步、隐藏=连点两次）*含时间参数的流程才显示、显示行数按页推进、位置记忆（右缘/左缘锚定）、全局快捷键表
6. **支持的游戏与获取建造顺序**：保留原项目各游戏网站信息（buildorderguide.com 等）
7. **下载与运行**：
   - EXE 版（原项目发布页）——**明确标注：旧版单窗口界面**
   - 从源码运行（本 fork，新版界面）——Anaconda/conda 步骤保留 + pynput/Python 3.13 兼容性提示
   - 网页版（rts-overlay.github.io）——注明网页版保持原项目逻辑，未做改版
8. **故障排查**：保留原文有用部分（浏览器建议、zip 解锁、Defender、Linux 置顶）+ 更新为管理器/悬浮窗语境
9. **补充说明**：GPL 与暴雪声明保留 + 新增"本 fork 改动概览"段落（简述 R2/R3 差异）

图片处理：保留游戏内演示图（aoe2/aoe4/aom 建造顺序演示动图与静图）；**移除旧界面面板截图引用**（aoe2_panel_configuration.webp 等 4 张，新界面无对应截图）。
