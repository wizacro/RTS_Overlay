# [2.15.0-cn.1] - 2026.09.27
* 本中文版（fork）相对原项目 2.15.0 的改动：
    * 界面
        * 全部界面文案简体中文汉化，新增浅色/深色主题（默认浅色）。
        * 新增管理器窗口：导入/展示双标签页、四步使用指引（可点击直达）、游戏下拉切换。
        * 悬浮窗改为移动/固定双模式：移动=整窗拖动，固定=按钮可点、其余区域穿透。
        * 悬浮窗自带隐藏按钮（连点两次防误触）；无时间参数的流程不显示计时按钮。
        * 新增"显示行数"设置（1-5，默认 3）：手动模式按页推进流程。
        * 流程列表支持右键重命名/删除（删除=移入"弃用区"文件夹）。
        * 从剪贴板一键导入流程（名称栏可自定义）。
    * 文档
        * Readme 与 Changelog 重写为中文，按新界面组织。
    * 其他
        * 流程与设置改为保存在工具目录的 local_config 文件夹（便携式，不写入系统目录），首次运行自动迁移旧配置。
        * 打包调整：EXE 位于压缩包根目录，方便查找与启动。
